# Instrument samples — attribution

Piano, violin, and guitar (nylon) note samples in this directory are
rendered from the **FluidR3_GM** SoundFont, redistributed via
[gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts)
(MIT-licensed repo; audio released under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/us/)).

A sparse set of notes (roughly every major third, C2–C7) was selected per
instrument for `Tone.Sampler` to pitch-shift between (U50).
